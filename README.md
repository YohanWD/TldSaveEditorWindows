# TLD Survival Save Editor (C# / WPF)

Editor for The Long Dark **Survival mode** saves (`%LOCALAPPDATA%\Hinterland\TheLongDark\Survival\sandbox*`).

```
dotnet run --project src/TldSaveEditor
```

Or open `TldSaveEditor.slnx` in Visual Studio. Requires the .NET 10 SDK.

## Projects

| Project | What it does |
|---|---|
| `src/TldSave.Core` | Save file library, no UI. `Lzf` (compression), `TldJson` (JSON with NaN/Infinity and nested JSON strings), `SaveFile` (load/save), `Inventory`, `SaveLocator` (find saves, backups) |
| `src/TldSaveEditor` | WPF app: save list, Overview, Inventory (condition, add/remove, raw gear JSON), Raw JSON viewer |
| `tools/CatalogBuilder` | Generates `ItemCatalog.json` from the saves on this PC (see below) |

## Item catalog ("Add item…")

`src/TldSave.Core/ItemCatalog.json` lists the items you can add. Notes, collectibles and keys are left out.
It is generated by `tools/CatalogBuilder`, which reads every save on this PC: the player inventory, plus the
containers and loose items of every visited scene. It can also read the original TS editor's item list.

For each item found in a save, a real sample becomes a "fresh item" template: full condition, stack of 1,
full calories, dry, not equipped. Position, ID and quest links are removed. New items then get the right
data, for example an insulated flask gets its (empty) contents data.

To regenerate it after playing more or after a game update, run from this folder:

```
dotnet run --project tools/CatalogBuilder -- src/TldSave.Core/ItemCatalog.json ../TLD-Save-Editor-3-main/src/tldSave/availableItems.ts
```

In the Add item dialog, items marked *story/challenge only* or *unverified name* were not found in a Survival
save and may not work. Uncheck "Only items found in Survival saves" to see them.

## Applying changes in game

**Quit the game completely before loading an edited save.** The game keeps the save in memory, so going
back to the main menu and reloading uses the old data and ignores your changes. It may also overwrite
the edited file on its next save.

1. Exit The Long Dark completely (not just to the main menu).
2. Edit and save with the editor.
3. Start the game and load the save.

## Safety

- Every save writes a backup first, to `Documents\TldSaveEditor\Backups\`.
- Only saves with `m_GameMode = SANDBOX` can be opened.
- Load and save were checked against 22 real saves: decoded data is identical after a round trip.
- Validated in game (2026-10-25) with [docs/TEST_SAVE_CHECKLIST.md](docs/TEST_SAVE_CHECKLIST.md): 66 added items
  of every component type, quantity / condition / remove edits, then a game save, reload and re-edit. No issues.
- A custom prefab name typed in "Add item" is not validated, and the game may drop a wrong one.
